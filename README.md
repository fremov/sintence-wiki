# Sintence Wiki

Учебная вики по устройству Sintence — для тех, кто знает основы C++ и хочет
доработать приложение сам. Это **не замена** документам проекта, а путеводитель
по ним: здесь «что это и как связано», там — «почему так решили»
(`sintence-app/ARCHITECTURE.md` — главный документ, всегда главнее вики).

Снимок: приложение `0.2.31`, 2026-11-04.

## Как пользоваться при работе

1. Хочешь понять, как что-то работает, — найди его на странице 4 и иди по ссылкам
   на файлы.
2. Перед любой правкой пройди чек-лист со страницы 3 («Куда класть код») и
   страницы 8 (правила Riot).
3. Закончил — собери и прогони тесты (страница 2, 10).
4. Нашёл расхождение вики с кодом — **верь коду**, а вики поправь (ты в этом
   репозитории хозяин).
