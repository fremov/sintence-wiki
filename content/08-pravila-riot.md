# 8. Правила Riot и красные линии проекта

Нарушение этих правил может стоить проекту ключа Riot или аккаунтов игроков.
Полный текст — `sintence-app/POLICY.md`. Здесь — шпаргалка для самопроверки перед
любой новой функцией.

## Можно

- Всё, что отдаёт **Live Client Data API** (`127.0.0.1:2999`) — игрок и так это видит.
- Публичные данные Riot API (история матчей, ранги, мастерство) — через сервер.
- Показывать то, что игрок видит сам по Tab.
- Писать в клиент League (руны, заклинания) — **только по клику пользователя**.

## Нельзя

| Что | Почему |
|---|---|
| Показывать **скрытое** состояние противника: кулдауны, таймеры (например, ультимейтов), позиции вне видимости | Riot в 2025 году банил такие трекеры |
| Действовать **за игрока** (автоматически нажимать, ставить руны «сами» по событию) | запись — только по клику |
| Делать **выводы за игрока** (предсказывать позиции) | меняет информационное поле |
| Показывать **чужие руны и порядок прокачки** на карточках врагов | Live Client их не отдаёт, из истории доставать нельзя |
| **Внедряться в процесс игры** (DirectX hook, инъекции) | несовместимо с анти-читом Vanguard |
| Восстанавливать **скрытые клиентом имена** | игрок скрыт намеренно |
| Анализировать **скрытых игроков** (режим стримера) | «products cannot identify or analyze players who are deliberately hidden» |
| Читать `obfuscatedPuuid`, `obfuscatedSummonerId`, эндпоинты `lol-lobby-team-builder` | запрещено навсегда |
| Использовать логотипы и эмблемы Riot в интерфейсе | свои иконки или текст |

## Технические красные линии

- **Ключ Riot** никогда не попадает в репозиторий, exe, журнал, интерфейс.
- **Токен пользователя**, **пароль lockfile LCU** — не в журнал, не в вывод, не в коммит.
- **Сервер приложения слушает только `127.0.0.1`.**
- Запись в LCU — только через `data/lcu_actions`, только из `POST /api/champselect/*`
  под `TrustedWrite`.
- Данные Riot, история, пак — **не на диске пользователя**. В `%LOCALAPPDATA%\Sintence`
  только журнал и данные WebView2.
- Новый метод Riot — строка в `ROUTES` на сервере в том же изменении.
- Нельзя `std::println` в `src/` — журнал через `Log`.

## Самопроверка перед коммитом

1. Данные, которые я показываю, игрок и так видит сам?
2. Приложение что-то делает *за* игрока или *вместо* клика?
3. Не появился ли новый запрос в Riot мимо шлюза?
4. Не попал ли секрет в строку журнала (проверь все `Log(...)` рядом со своими
   правками)?
5. Не нарушена ли зависимость слоёв (страница 3)?

Сомневаешься — спроси заказчика до кода, а не после.
