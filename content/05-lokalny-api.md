# 5. Локальный API

Граница между C++ и интерфейсом — **HTTP + JSON на `127.0.0.1:8777`**
(`app/live_api_server.cpp`). Интерфейс ничего не знает о C++, а C++ — о Vue.

> Номера строк ниже — на 2026-11-04 и уплывают. Ищи по пути маршрута: `grep '"/api/live"'`.
> Комментарий в начале `live_api_server.h` **неполный** (нет 12 маршрутов) и в одном месте
> ошибочный (про 501 у `/api/preferences`) — главный список здесь.

## Устройство в трёх строках

- Все маршруты регистрируются подряд в одной функции `LiveApiServer::Start()` лямбдами
  `[this]` на `httplib::Server` (строки ≈1100–2379).
- Ответ: `nlohmann::json` → `.dump()` → `set_content(..., "application/json")`.
  Типовые ошибки — готовые строки вида `{"error":"..."}`.
- Один фоновый поток слушает порт, запросы обслуживает пул потоков httplib.

### Статика

`GET /*` — интерфейс. По умолчанию отдаётся **из файлов, вшитых в exe**
(`EmbeddedWebFiles`); с диска (`dist/`) — только если задан `SINTENCE_WEB_DIR`.
`.html` идёт с `Cache-Control: no-cache`, неизвестный путь — 404.
Этот маршрут регистрируется **последним**, иначе он перехватил бы `/api`.

## Что значат коды

| Код | Смысл в этом проекте |
|---|---|
| `200` | есть; у POST-действий — «запрос принят», исход в `status` |
| `202` | принято, ещё готовится (timeline, проверка обновления) |
| `400` | не хватает/испорчен параметр |
| `403` | POST не из интерфейса (`TrustedWrite`) |
| `409` | конфликт состояния (нечего обновлять, идёт игра, legacy-токен) |
| `501` | функция выключена в этой настройке (нет сервера) |
| `503` | временно нет: матча нет, пак/плашки ещё не приехали, сервер Sintence не ответил |

### Почему `/api/preferences` отвечает 503

| Причина | Условие |
|---|---|
| пак ещё не приехал | сервер есть, но `PackStore` пуст |
| нет матча и нет `champion` | нечего считать |
| нет активного игрока | например, режим наблюдателя |
| активного игрока нет на табло | |

`501` — только когда нет сервера вообще.

## Защита записи (`TrustedWrite`)

Любая страница в браузере может послать запрос на `127.0.0.1:8777`. Поэтому **все 7 POST**
(runes, spells, spectate, update/check, update/apply, badge-visibility, autostart) проверяют:

| Что | Допустимо |
|---|---|
| заголовок `X-Sintence-Action` | ровно `1` |
| `Host` | `127.0.0.1:<порт>` или `localhost:<порт>` |
| `Origin` | пустой (пропускается) **или** `http://127.0.0.1:<порт>`, `http://localhost:<порт>`, `http://localhost:5173`, `http://127.0.0.1:5173` (Vite) |

Отказ — `403 {"error":"forbidden"}`. Функция `TrustedWrite` — около строки 344.
**Не ослабляй**: иначе чужая страница сможет менять руны игрока.

## Подводные камни (на что наткнёшься в этом файле)

1. **Тип поля в JSON.** `body.value("key", 0)` бросает исключение, если поле есть, но другого
   типа; httplib превратит его в 500. Проверка `is_discarded()` ловит только синтаксис.
2. **Порядок маршрутов.** Статика с `/.*` — последняя; новый маршрут добавляй **выше** неё.
3. **`Pack()` возвращает `shared_ptr` по значению.** Пак может смениться посреди запроса,
   а старый доживёт до конца ответа. Не сохраняй из него сырые указатели надолго.
4. **Порядок членов `Impl`** — по объявлению, а не по списку инициализации: `ranks` и
   `ladder_friends` берут `sintence_server`, который обязан быть объявлен выше.
5. **Мьютексы.** `averages_mutex`, `mmr_mutex`, `skins_mutex` — каждый на свой кеш;
   `static std::mutex` внутри лямбды `/api/preferences` — один на все запросы.
6. **Выход без деструкторов.** `main` завершается через `std::_Exit`, поэтому `Stop()`
   сервера может не вызваться — не рассчитывай на очистку в деструкторах.
7. **Кеш картинок скинов не ограничен** и живёт до конца запуска.

## Как попробовать руками

Порт по умолчанию **8777** (рабочая копия заказчика). Своя отладочная копия — на 8778:

```powershell
$env:SINTENCE_PORT = "8778"
curl http://127.0.0.1:8778/api/health
curl http://127.0.0.1:8778/api/live          # 503, если матча нет — это норма
curl "http://127.0.0.1:8778/api/preferences?champion=Ahri&role=MIDDLE&enemies=Zed"
```

## Рецепт: свой эндпоинт

1. Типы результата — в `core/`, если это домен; логика — в `analysis/` или `data/` с тестами.
2. Обработчик — в `Start()`, **выше** маршрута статики. Возьми соседний как образец
   (для GET с параметрами — `/api/meta`, для POST — `/api/spectate`).
3. JSON собирай через nlohmann **только в `app/`/`data/`**; числа из query — через `IntParam`.
4. Для POST начни с `if (!TrustedWrite(...)) return 403`.
5. Схема в `sintence-web/src/api/schemas.ts` + мок + версии, если ломаешь контракт.
6. Добавь маршрут в таблицу выше (и, если хочешь, в комментарий `live_api_server.h`).
