# 5. Локальный API

Граница между C++ и интерфейсом — **HTTP + JSON на `127.0.0.1:8777`**
(`app/live_api_server.cpp`). Интерфейс ничего не знает о C++, а C++ — о Vue.
Полное описание — комментарий в начале `live_api_server.h` (читай его, он точный).

## Карта эндпоинтов

| Путь | Что | Особые коды |
|---|---|---|
| `GET /api/health` | версия контракта `kApiVersion`, включённые функции, версия приложения, состояние обновления | |
| `GET /api/live` | снимок матча | `503` — матча нет |
| `GET /api/lobby` | состав до матча (LCU, spectator) | `phase` пустая — клиент не запущен |
| `GET /api/profiles` | профили игроков табло/лобби + прогресс | `501` — нет сервера |
| `GET /api/preferences` | советы по сборке | `501` нет пака/сервера, `503` ни матча ни параметров |
| `GET /api/profile`, `/api/matches`, `/api/matches/{id}[/timeline]` | окно статистики | `202` — timeline качается |
| `GET /api/players?q=` | подсказки ника | |
| `GET /api/badges` | правила плашек (с сервера как есть) | `503` ещё не приехали |
| `GET /api/meta`, `/api/trends`, `/api/averages`, `/api/mode-champions` | вкладки «Мета», «Динамика», средние, скамейка | |
| `GET /api/ladder`, `/api/friends`, `/api/active-game[/cards]` | лестница, друзья, идущая игра | |
| `POST /api/champselect/runes\|spells` | записать руны/заклинания в клиент | `403` — запрос не из интерфейса |
| `POST /api/update/check\|apply` | обновление | `409` — идёт игра |
| `POST /api/spectate` | «смотреть в клиенте» | |
| `GET /*` | статика интерфейса (`dist/`) | |

Статусы осмысленные: `503` — «ресурс есть, временно недоступен», `501` — «эта
сборка/настройка функцию не поддерживает», `202` — «принято, ещё готовится».

## Правила изменения контракта

Ответ API — это договор с `sintence-web`. Договор живёт в двух местах:

| Место | Что |
|---|---|
| C++ | `kApiVersion` в `live_api_server.cpp` |
| Интерфейс | `EXPECTED_API_VERSION` в `sintence-web/src/composables/useHealth.ts` и zod-схемы в `sintence-web/src/api/schemas.ts` |

- **Добавил поле** — достаточно обновить zod-схему (новое поле необязательное) и моки
  (`sintence-web/src/mock/`).
- **Удалил поле или поменял тип** — обновить схему **и поднять обе версии
  в одном заходе**. Иначе интерфейс либо сломается, либо молча покажет мусор.
- Схема проверяет ответ на границе (`client.ts`): несовпадение видно сразу.

(Актуальные номера не запоминай — смотри `grep kApiVersion`; в документах они
бывают устаревшими.)

## Защита записи (`TrustedWrite`)

Любой сайт в браузере может послать запрос на `127.0.0.1:8777`. Поэтому POST,
меняющие что-то в клиенте игры, проверяют:
- заголовок `X-Sintence-Action`;
- `Host` — только локальный;
- `Origin` — только свой.

**Не ослабляй** эту проверку: иначе чужая страница сможет менять руны игрока.

## Как попробовать руками

```powershell
curl http://127.0.0.1:8778/api/health
curl http://127.0.0.1:8778/api/live          # 503, если матча нет
curl "http://127.0.0.1:8778/api/preferences?champion=Ahri&role=MIDDLE&enemies=Zed"
```

## Как добавить свой эндпоинт (рецепт)

1. Типы результата — в `core/` (если это домен).
2. Логика — в `analysis/` или `data/` с тестами.
3. Обработчик — в `LiveApiServer` (смотри соседние `Get`-обработчики и вспомогательные
   функции сборки JSON).
4. Ответ сериализуй через nlohmann **только в `app/`/`data/`**.
5. Схема в `sintence-web/src/api/schemas.ts` + мок + `kApiVersion`, если ломаешь.
6. Запиши эндпоинт в комментарий `live_api_server.h` (там живёт «главный список»).
