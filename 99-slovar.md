# Словарь

| Термин | Что значит |
|---|---|
| **Live Client Data API** | официальный локальный API игры, `https://127.0.0.1:2999`, только во время матча |
| **LCU** | League Client Update — неофициальный локальный API клиента League; порт и пароль в файле lockfile |
| **lockfile** | файл клиента с портом и паролем LCU. Пароль нельзя логировать |
| **Match-V5** | API Riot с историей завершённых матчей |
| **spectator-v5** | API Riot «идущая игра игрока»; используется на экране загрузки |
| **puuid** | постоянный идентификатор игрока Riot |
| **Riot ID** | `Имя#ТЭГ` — отображаемый идентификатор |
| **платформа / регион** | хост Riot: платформенный (`ru`) или региональный (`europe`) — разные API на разных |
| **Data Dragon / CommunityDragon** | статические данные игры: названия, иконки чемпионов, предметов, рун по id |
| **perk** | руна; **keystone** — ключевая руна; **shard** — осколок статов |
| **ORDER / CHAOS** | синяя / красная команда |
| **пак предпочтений** | JSON с агрегированной статистикой сборок (руны, предметы, прокачка, заклинания) по чемпиону/роли/противнику/рангу |
| **матчап** | пара «мой чемпион против этого» |
| **корзина (bucket, tier)** | группа рангов: BRONZE, GOLD, EMERALD, DIAMOND, ALL |
| **лестница отката** | порядок поиска совета: от точного матчапа к общему |
| **плашка (badge)** | значок стиля игры (правила на сервере, оценивает интерфейс) |
| **оверлей** | окно приложения поверх игры |
| **peek** | быстрое показать/спрятать оверлей горячей клавишей без фокуса |
| **WebView2** | встроенный в Windows Chromium для окон приложения |
| **шлюз** | серверная прослойка `/v1/riot/...`: держит ключ Riot, лимит и кеш |
| **пульт (dashboard)** | панель управления сервером |
| **краулер** | сервис сбора матчей |
| **heartbeat** | «пульс» приложения на сервер раз в минуту |
| **CI** | автоматическая сборка и проверка в GitHub Actions |
| **ASan** | AddressSanitizer — детектор ошибок памяти в Debug-сборке |
| **vcpkg** | менеджер C++-библиотек |
| **триплет** | набор целевых настроек vcpkg (`x64-windows-static`) |
| **portable** | один exe без файлов рядом |
| **ARAM / Хаос (MAYHEM)** | режимы игры; Live Client называет Хаос `KIWI` |
| **TrustedWrite** | проверка заголовка, Host и Origin на POST, меняющих клиент игры |
| **Vanguard** | анти-чит Riot; не терпит внедрения в процесс игры |
| **подмодуль git** | репозиторий внутри репозитория, закреплённый на конкретном коммите |
