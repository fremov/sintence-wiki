# 7. Сервер (sintence-data)

Отдельный репозиторий на Python. **Приложению он нужен как источник данных,
правишь ты его редко.** Главное — знать, что за ним стоит.

> ⚠ **Push в `sintence-data` — это выкладка на боевой сервер** (CI → ветка `release` →
> через ~2 минуты код работает у всех). Не пушь туда без согласования с заказчиком.
> `sintence-app` и `sintence-web` тоже пушатся только по его просьбе.

## Зачем сервер

1. **Ключ Riot** — personal-ключ с жёстким лимитом: 20 запросов/с и 100 за 2 минуты
   на всё вместе. Один ключ на всех пользователей, поэтому лимит держит сервер, а
   приложение ходит через **шлюз** и не знает ключа.
2. **Кеш ответов Riot**: повторная загрузка профиля ключ не тратит.
3. **База матчей** (PostgreSQL): краулер собирает ранговые матчи текущего патча.
4. **Пак предпочтений**: статистика «что берут на этом чемпионе против этого» —
   основа советов.
5. **Пульт** (dashboard): состояние сбора, ошибки, пользователи, правила плашек.

## Службы (docker compose)

| Служба | Роль |
|---|---|
| `db` | PostgreSQL 18, матчи секционированы по патчу |
| `crawler` | сбор матчей без остановки (только текущий патч, ранги поровну) |
| `maintain` | место на диске, сборка пака раз в 6 ч и при смене патча |
| `api` | **шлюз**: белый список маршрутов Riot, кеш, профили, пак, регистрация |
| `dashboard` | пульт на `127.0.0.1:8790` (через туннель) |
| `proxy` | Caddy, HTTPS наружу |
| `backup` | `pg_dump` ночью, 7 копий |

## Как приложение с ним разговаривает

| Что | Путь | В C++ |
|---|---|---|
| Запрос в Riot | `/v1/riot/<хост>/<путь>` | `RiotApiClient` → `ServerConfig` |
| Регистрация | `POST /v1/register` | `server_auth` |
| Пульс | heartbeat | `app_heartbeat` |
| Пак | `/v1/packs/index.json` → файл | `PackUpdater`/`PackStore` |
| Матчи игрока из кеша | `/v1/history` | `HistoryService` |
| Подсказки ника | `/v1/players` | `ServerClient` |
| Плашки | `/v1/badges` | `BadgeStore` |
| Обновление exe | `/v1/app/latest` | `app_update` |

**Токен** — у каждого пользователя свой: получает при первом запуске
(`POST /v1/register`), хранит в диспетчере учётных данных Windows
(`Sintence/<хост>`). В exe токена нет, в журнал и интерфейс он не попадает.
Шлюз — **не открытый прокси**: новый метод Riot добавляется строкой в `ROUTES`
(`api/server.py`) в том же изменении, что и клиентский код.

## Чем ограничена разработка

- Без сервера (`SINTENCE_SERVER` не задан) приложение работает «наполовину»: табло и
  выбор чемпиона есть, профили/история/советы — `501`.
- Для учёбы можно работать только с табло (запусти Practice Tool) и с тестами.
- Сервер доступен по ssh только заказчику. Если нужно что-то узнать с сервера —
  проси его.
